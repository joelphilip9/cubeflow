# CubeFlow

CubeFlow is a visual Rubik’s Cube practice tool. Pick a 2×2, 3×3, or 4×4 cube, enter each face through a guided scan, then follow the animated move route in the interactive 3D cube.

## Live site

https://cubeflow-neon.vercel.app/

## What it includes

- Guided six-face color entry that keeps the scan order clear
- Interactive Three.js cube with orbit, zoom, and move animation
- Animated previous/next solution playback
- Beginner-friendly links for move notation and cube tutorials

## Run locally

This project is plain HTML and JavaScript. Open `index.html` in a modern browser, or serve the folder with any static web server.

## Notes

CubeFlow is designed for deliberate visual practice. Always enter each face while keeping the physical cube orientation consistent.
